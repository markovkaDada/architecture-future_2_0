
## Проблемные места

| Проблема                        | Описание                                                                           | Влияние на бизнес                                             |
|---------------------------------|------------------------------------------------------------------------------------|---------------------------------------------------------------|
| **Монолитная архитектура DWH**  | Вся бизнес-логика сосредоточена в одном SQL Server, что затрудняет масштабирование | Медленная интеграция новых бизнесов, высокие риски отказа     |
| **Устаревшие технологии**       | SQL Server 2008, PowerBuilder - технологии 15-летней давности                      | Сложность найма специалистов, ограниченная функциональность   |
| **Производительность**          | Сложные отчеты выполняются часами из-за объема данных (сотни ТБ)                   | Медленное принятие решений, низкая продуктивность сотрудников |
| **Отсутствие самообслуживания** | Пользователи не могут самостоятельно создавать отчеты                              | Высокая нагрузка на IT-отдел, медленный time-to-market        |
| **Слабая интеграция**           | Старая шина данных Apache Camel не справляется с растущими потребностями           | Сложность добавления новых источников данных                  |
| **Смешение данных**             | Медицинские и аналитические данные в одном хранилище                               | Проблемы с безопасностью и производительностью                |
| **Отсутствие governance**       | Нет централизованного управления метаданными и качеством данных                    | Недоверие к данным, дублирование усилий                       |
